# Electric-board-v3
2026年高専祭で展示する予定の電光掲示板です

# 概要
32 * 32ドットのマトリクスが搭載されたドライバ基板を4枚横につなげることで32 * 128ドットの電光掲示板にする。ドライバ基板のジャンパ(JP1,JP2)を繋げば輝度調整も技術的には可能

# 使用技術
- MD1516C2-RG ドットマトリクスLED
  赤色と緑色のアノードコモン2色16×16LEDマトリクス。同時点灯を行うと赤緑橙の3色点灯が可能。このマトリクスをドライバ基板1枚に4個配置し、ドライバ基板を直列につなげることで32×128ドットの電光掲示板を作成する。
- 74HC595
  8bitシフトレジスタ。カスケード接続され、マイコンから送られたシリアル信号をパラレル信号へ変換する。
- PchMOSFET
  大電流が流れるアノード側スイッチング用。アクティブLowであることに注意。
- ダイナミック点灯
  電流を流すアノード(行)を変え続けることで使用するピン数と電流を削減する。
- PIO
  Programmable I/O。Raspberry Pi Picoに搭載されたピンの操作に特化したプロセッサ。PicoのCPUとは分離されており、1クロック単位でピンの入出力を制御できる。
- DMA
  Direct Memory Access。Raspberry Pi PicoのメモリとPIOをCPUを介せず高速に転送する。


# ピンアサイン
ドライバ基板の端子アサイン
## 6pinピンヘッダ・ソケット(QI)
```
+---+---+=======+---+---+
| 1 | 2 | 3 | 4 | 5 | 6 |
+---+---+---+---+---+---+
```
※デフォルトでは基板側のOEピンはプルダウンされています。使用する場合はドライバ基板のJP1かJP2、あるいは両方のジャンパを短絡してください。
1. アノードデータ
2. 赤色LEDカソードデータ
3. 緑色LEDカソードデータ
4. 74HC595 シフトレジスタクロック(SRCLK)
5. 74HC595 ストレージレジスタークロック(RCLK)
6. 74HC595 アウトプットエネーブル(OE)

## 電源ピン(VHコネクタ)
```
+=======+
| 1 | 2 |
+---+---+
```
※ドットマトリクス側が下
1. 5V電源+
2. GND電源-
